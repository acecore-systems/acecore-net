# 全体構造

## 構成

| 区分                         | 役割                                                             |
| ---------------------------- | ---------------------------------------------------------------- |
| Astro                        | 9言語の静的ページと公開UIを生成する                              |
| `src/data/`                  | 固定ページ、サービス、料金、実績などの構造化コンテンツを保持する |
| `src/content/insights/`      | 技術解説と翻訳を保持する                                         |
| Sveltia CMS                  | 日本語のCMS管理対象コンテンツとメディアを編集する                |
| Cloudflare Pages / Functions | GitHub連携による公開とCMS保存時の検証を担う                      |
| Pagefind / Vectorize         | 日本語のキーワード検索と補助的な関連検索を提供する               |

## 公開経路

1. Pull RequestまたはCMS保存で`main`の内容を更新する。
2. Cloudflare PagesのGitHub連携が公開ビルドを開始する。
3. 公開済みの日本語HTMLから検索用corpusを生成し、Productionの補助検索だけを同期する。

## 安全な分離

- Pages PreviewはVectorize bindingを持たず、キーワード検索を維持する。
- Vectorizeは公開済みの日本語情報を派生データとして扱い、サイト本文の正本にしない。
- CMSの認証・権限確認・書込み対象は運用設計で明示する。
