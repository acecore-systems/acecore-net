2026-10-24、全体彩色の採用後、ユーザーが「ロゴの真ん中の丸は常に公式の青」、続いて文字は「Acecoreは真ん中のcだけ、子ページ名は頭文字だけ」と指定した。その後「濃い背景の時は真ん中無地でいい」と指定したため、中央は明背景で単色#0656d9、濃い/テーマ背景で外周と同じ白単色とする。wordmarkはAcecoreの2つ目のc（index3）だけ公式青、子名の頭文字だけ事業色を維持する。中央常時blueと文字全体を着色する旧規則を上書きする。本書はAcecore公式・Systems・Schools・Designsの現行基準。ファイル名は既存の参照先を保つため変更していない。

## 採用ロゴ

### 明るい背景

外周4描画pathへ同一の有彩色radialを適用し、中央2描画pathは単色#0656d9とする。外周の暗い材質と薄い材質で別の色面を作らない。白いハイライト、黒沈み、金属的な反射筋や折り目は加えない。左上から右下へ広く円弧状に色をつなぐ。

| サイト  | 色停止点                                                            |
| ------- | ------------------------------------------------------------------- |
| 公式    | 0% #2675df → 50% #0656d9 → 100% #17459d                             |
| Systems | 0% #8950c5 → 50% #765bd0 → 100% #0656d9                             |
| Schools | 0% #39a86b → 50% #278b91 → 100% #0656d9                             |
| Designs | 0% #e6b847 → 25% #e98f85 → 50% #d780ba → 75% #8970cf → 100% #0656d9 |

SVGのviewBoxは375×374.999991。主radialはuserSpaceの起点80/72、半径380/340（gradientTransform: matrix(380 0 0 340 80 72)）。全path/clip座標・比率・余白を保持する。CSSの--logo-paintは全ロゴ領域を基準に ellipse 101.333% 90.667% at 21.333% 19.2% と同じ停止点へ同期する。旧--sphere-paintは廃止し、球だけの白光沢tokenを残さない。

### テーマカラー背景

背景側へ事業paletteを使い、中央を含め全6描画pathを#ffffffの単色にする。白版SVGにはgradient定義を持たせない。テーマの背景は ellipse 120% 135% at 0% 0% の広いradial。公式は前回の背景停止点0% #2675df → 50% #07337c → 100% #05245aを維持する（今回の中央whiteに合わせた不要な背景変更はしない）。説明captionは白い読み面へ分ける。

通常ページは白主体のまま。ロゴのために全footerや全sectionを色面へ変えず、既存の色背景上で使う場合やOGなどの必要な箇所だけテーマ背景＋白版へ揃える。

### 画像の選択とfavicon

- 文書内imgは実背景で明示選択する。白いheader/footerは/logo.svg、テーマ背景は/logo-on-dark.svg。OSがdarkであることだけを理由に白いheaderのロゴを白くしない。
- /favicon.svgは専用asset。明外観は外周テーマ色・中央青、暗外観はテーマ背景rectと中央も含め全白のロゴへCSS mediaで切り替える。元の形状・余白を縮めず背景を追加する。375の正方形基準で背景radialは起点0/0、半径450/506.25。
- 文書内imgにadaptive faviconを流用せず、全白filterや白い四角の下地だけで代用しない。
- 公式のコード生成OGは既存青背景の左側に白い読み面を設け、cだけ青いAcecore文字と明背景版ロゴを置く。Designsのコード生成OGは白読み面上なので全体彩色版を使う。文字・構図を保持しロゴと必要な背景だけ同期する。写真を使うSchools/SystemsのOGは差し替えない。

## UIの色と使用量

- 共通青は#0656d9。Systems紫#8950c5、Schools緑#39a86b、Designsは黄・橙・ピンク・紫から青への多色。似た色を独立追加せず名前付きtokenで管理する。
- header/footer/部門ブランド見出し/OGでは、Acecoreの2つ目のc（index3）だけ#0656d9、Systems/Schools/Designsは頭文字だけ事業色。残りは中立色#20252b。DesignsのDは読みやすい#986000 → #b33e71 → #8146ae → #0656d9を使う。通常本文の社名は細分化しない。
- テーマ色はロゴ・名称・短いラベル・リンク・主要CTA・選択状態・要所の罫線に絞る。全UIで一貫させることは全要素の着色を意味しない。
- 通常のh1/h2/h3、長文、料金数値は原則#20252b。白い読み面を主体とし、普通の表枠や区切りは中立色。全sectionをwashで埋めない。
- UI操作部品の--paint、文字用濃色、washは既存の読みやすい組み合わせを保持する。ロゴ全体彩色の採用は本文や料金の色変更を意味しない。Schoolsの主色に小さい白文字をそのまま載せない。
- 成功・警告・エラーの意味色、写真・実作品・記事図の内容上の色は維持する。公式内の部門名はSystems紫・Schools緑・Designs多色。

## 保全と検証

写真・Hatt・実作品・図・本文・価格・条件・翻訳・CMS・フォーム・検索・AI・多言語経路を保持する。画像の差し替えは個別指示が必要。コード生成ブランドOGとロゴSVGの今回許可された色表現だけを更新する。

変更時は既存配置、明暗外観、16/32/64pxと拡大、desktop/mobile、OGを確認する。path/clip/余白/比率を機械比較し、明背景版の中央blueとテーマ背景版の中央white、faviconの背景切替を検証する。build・format・diff checkと必要な既存検証を実行し、ローカル・CI・Preview・マージ・本番を別の状態として記録する。

対象はacecore-systems/acecore-net、acecore-systems/acecore-systems、acecore-systems/acecore-schools、acecore-systems/acecore-designs。各repoのAGENTSとブランドガイドから本書を参照する。

## 描画の境界と名前の組版

- CTAとfooterの接する境界に別々のgradient枠を重ねない。境界帯はfooterの4pxの単一面を正本とし、section全高を基準にした多層border背景を使わない。
- 共通BrandWordで色付き1文字を分け、余計な空白を入れず、textContent・aria-label・読み上げ・字間を保持する。DesignsのDはinline-blockと余裕ある行高・上下余白で描画する。
- 通常viewportのoverflowとpinch zoomによる視野の狭まりを区別し、ユーザーの拡大操作は無効化しない。

Systems/Schools footerのimgに残っていたborder-radius:50%とpadding:4pxが対角の矢印先端を切っていた。円形クリップを除去して原SVGの形状を復元し、viewBox/path/clip/余白は変更しない。ロゴimgや祖先へ円形clip/maskを適用せず、通常viewportのoverflowだけでなく実寸の図形欠損も確認する。

最新の背景別中央規則: --logo-centerは明背景用#0656d9、--logo-center-on-themeは濃背景用#ffffff。wordmarkのc/子頭文字、円形clip除去、明背景OG、写真・本文は変更しない。
