## 判定基準

同じ操作は位置・意味・キーボード操作を揃える。各サイトの目的、既存API、提供内容、作品、画像、料金、翻訳を同一化しない。既存16社の比較記録とDesignsの20サイト調査を再利用し、新規の競合確認済みとは扱わない。

## 証拠と制限

証拠はタスクの `shared-ui-refinement/` に保存。`before/route-audit.json`、3chat開始状態、`after/chat-evidence.json`、代表画面、変更後ルート監査を対応づける。Browser/IABは利用不能のため、承認済みの管理Chromium/WebKitを使用する。WebKitは実iOS端末とは区別する。

chatの回答・送信待ち・errorはAPIをroute interceptionしたfixture。実API送信、実Turnstile送信、実機キーボードは未実施。visualViewportの追従、pagehide/SPA/bfcacheのlistener再初期化を実装し、狭い高さでclose/送信へ到達することを確認する。記事コメントAPIの静的preview制限はサイト表示の回帰と区別する。

## 今回の結果

- 変更後104画面は全HTTP200・横溢れ0・監査対象の44px未満操作0。代表8画面のmenu/Escape/focus/現在ページと3サイトの長いドイツ語表示を確認。
- chatは3サイト×Chromiumの390×667・320×480・1440×900、およびWebKit390×667の計12条件が成功。初期scrollTop0、IME Enter/Escape、Shift+Enter、busy再送防止、mock長文/error、close後focusを確認。マウスclickでbuttonへfocusしないWebKitでもbodyへ戻さずlauncherへ復帰する。
- SystemsのCTA意味・高specificityアンカーは最終build後に限定再確認し112pxを確認。Schoolsの価格3値は中立色、FAQ開閉、検索fallbackを確認。Systemsのローカル検索結果URL制約は実APIの成功とは扱わない。
- 4サイトのbuild成功。公式content/corporateとAI103テスト、Designs catalog26テスト、Schools chat4テスト、Systemsの指定prebuild/content/i18n/既存AIテストと出力検証が成功。移動したCSSを古いclassで検査していたテストは共有CSSの16px入力という同じ不変条件へ更新した。
- 既存data/content/i18n・写真/作品・ロゴSVG・API/backendは変更なし。Designsの生成OGだけブランド区切りslashを削除して再生成し、構図・文字・作品を保持。

実行は `npm run build`（4サイト）、`npm run validate:content`（公式/Designs、Systemsはprebuild）、`npm run validate:corporate`（公式）、`npm run test:ai-chat`（公式/Schools）、`node node_modules/prettier/bin/prettier.cjs <変更対象> --check`、`git diff --check`。Schoolsのformatは親repo設定の探索を避け、同サイト従来の既定値（semi有効・singleQuote無効・Astro plugin）を明示した。ブラウザ証拠は `route-audit.mjs after`、`chat-qa.mjs`、`ui-qa.mjs`、`limited-qa.mjs`。
