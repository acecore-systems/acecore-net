# 全面刷新のための追加調査

確認日: 2026年10月23日。前回の公式12社比較に追加し、企業の印象をつくる文字・画像・色面・余白と、その下層ページへの展開を調査した。今回は既存内容の保全を条件に、構成と視覚表現を全面的に変更する。

## 調査範囲と画面証拠

内蔵ブラウザが利用不可だったため、Playwright管理Chromiumの専用ブラウザを使用。ユーザーの通常ブラウザのプロファイルは利用していない。公開ページを閲覧し、フォーム送信はしていない。

追加候補6社のうち4社はデスクトップ・モバイルのトップ全体を目視し、それぞれ下層1ページも確認。Sun*とWantedlyは動的部分の描画が欠けたため、全体の視覚評価から除外した。前回12社と今回4社が視覚比較の根拠であり、18社すべてを同等に検証したとは扱わない。

証拠はセッションの `redesign-references/` に保存。`evidence.json` と `details-evidence.json` に最終URL・タイトル・見出しを記録した。`*-full.png`、`*-mobile.png` と下層ページ画像を目視した。長いページの縮小画像は構成把握用であり、細かな文字の読みやすさの保証ではない。

## モバイルから得た具体的な方針

4社ともデスクトップの横配置をそのまま縮小するのでなく、主要な言葉と画像を縦に再構成していた。ニュースは日付・分類・題名の順序を保ち、必要に応じて小さな横画像を使う。モバイルのフッターを折りたたむ例もあった。

Acecoreでは日本語390pxだけでなく長い翻訳文にも対応し、見出しの強さを保ちつつ、意味の不自然な改行・固定高による切れ・小さすぎる補助文字を避ける。メニュー・言語・検索・チャットは画面を占有する状態も別に検証する。

## 今回の判断

- 白地・濃紺・青を軸とした一貫した書体、余白、罫線、リンク、フォームの体系をつくる。
- ホームは理念、事業、会社、ニュース、相談の流れをつくる。同じカード形状を全セクションへ繰り返さない。
- 事業紹介は各部門を画像と説明の大きな章で見せ、個別サービス・料金の確認先へ進める。ホームの短い予告と事業ページの詳細は目的が異なる。
- 会社概要では理念の印象と会社の事実情報を両立させる。役員、法人情報、事業目的、理念本文を省略しない。
- 新規画像は技術・学び・創作という内容を具体的に伝える独自の表現にする。青い図形を置くだけ、架空UIを実製品として見せる、生成人物を社員・顧客実績に見せる使い方はしない。
- ニュース・記事・タグ・著者・アーカイブ、問い合わせ・完了、AceStudio、法務、404、検索、チャット、共通ナビも同じデザイン体系に刷新する。
- 内容の保全は「見た目を変えない」ことではない。元の情報・機能・行き先と新しい配置を対応表で照合する。事実や機能を消さずに、レイアウトは大きく変える。

前回の「変更を絞る」「画像生成は既存素材で不足する時のみ」という運用判断は、今回の全面刷新の制約にはしない。ユーザーは画像差し替えと大幅な改変を明示的に許可している。承認済み素材の権利・固定bytesは保全し、新しい独自素材を別の資産として追加する。
