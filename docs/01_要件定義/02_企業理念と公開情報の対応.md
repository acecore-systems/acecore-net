# 企業理念と公開情報の対応

確認日: 2026年10月23日

## 正本

確定したキャッチコピーは「世界を次のステージへ」とする。企業理念と「私たちの目指す姿」の本文は、[設立資料の企業理念（commit 379b201）](https://github.com/acecore-systems/for_incorporation/blob/379b2011728ae348e31574245bd13054db2d2cf9/企業理念/企業理念.md)を反映する。

2026年10月23日にGitHubの最新の正式文書（blob SHA `556a93514c42083d22bde52591342ff1b1d0ae76`）と照合し、現行の標語・企業理念5段落・目指す姿4段落が一致することを確認した。本番の会社概要にも同じ標語と本文が掲載されている。本文の書き換えは行わず、ページ内案内から理念と目指す姿に直接移動できるようにする。

「本質的でない時間を減らすこと」と「一歩を踏み出すための後押し」を一つの方針として伝える。要約では、社会全体への効果を達成済みの実績として記載しない。

| 資料                                  | 理由                                                                                           |
| ------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 企業理念-本心.md、企業理念への問い.md | 内部検討や未確定候補を含むため、確定した企業理念と混在させない。                               |

| 定款などの設立資料                    | 事業目的は既存の会社概要と対応している。公開に必要のない個人情報や設立手続き情報は転載しない。 |
